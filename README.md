# Kuangan

Aplikasi Flutter untuk mencatat pemasukan, pengeluaran, scan struk, dan integrasi Telegram bot.

## Menjalankan proyek

```bash
flutter pub get
flutter run
```

## Fitur utama

- Dashboard keuangan
- Manajemen dompet dan kategori
- Riwayat transaksi
- Scan struk
- Laporan
- Integrasi Telegram bot

## Panduan Telegram bot

Buka menu `Atur` di aplikasi lalu masuk ke kartu `Telegram Bot`.
Di sana sudah tersedia tombol `Cara pakai Telegram Bot` yang menjelaskan:

- cara mendapatkan Telegram ID
- cara menempelkan ID ke aplikasi
- cara mulai mencatat transaksi lewat bot
